# Weather Dashboard

A professional Power BI dashboard project for analyzing weather data retrieved from a weather API and presenting key meteorological insights through an interactive and visually engaging reporting experience.

![Weather Dashboard](Dashboard.PNG.png)

## Overview

This repository contains a Power BI dashboard, `Weather_Dashboard.pbix`, designed to visualize weather conditions, track climate trends, and compare meteorological metrics over time. The project is powered by weather data collected from an API, making it suitable for monitoring current and historical weather patterns in a structured, decision-friendly format.

The dashboard transforms raw API data into a clear analytical view using KPIs, trend charts, and comparative visuals that help users understand temperature shifts, precipitation levels, humidity patterns, and seasonal variation at a glance.

## Objectives

- Monitor weather conditions over time
- Compare climate trends across locations and seasons
- Analyze key variables such as temperature, humidity, and rainfall
- Present insights in an interactive, user-friendly dashboard
- Turn API-based weather data into actionable visual intelligence

## Features

- Interactive KPI cards for key weather indicators
- Temperature trend analysis over time
- Rainfall and humidity monitoring
- Seasonal and regional weather comparison
- Date and location-based filtering
- Clean, professional dashboard layout
- Ready-to-open Power BI report for quick exploration

## Tech Stack

- Microsoft Power BI Desktop
- Power Query for data transformation
- DAX (Data Analysis Expressions) for calculations and KPIs
- Weather API for data acquisition
- Data modeling and visual analytics

## Data Source

This dashboard uses weather data obtained from a weather API, including fields such as:

- Date and time
- Temperature
- Humidity
- Precipitation
- Wind speed
- Atmospheric pressure
- Region or city name
- Weather conditions and summaries

The API data is structured and transformed in Power BI to support dashboard reporting and trend analysis.

## Requirements

To open and work with the dashboard:

- Microsoft Power BI Desktop
- A compatible Windows environment
- Access to the weather API or a refreshed dataset

## How to Use

1. Download or clone this repository.
2. Open `Weather_Dashboard.pbix` in Power BI Desktop.
3. Refresh or connect the data source if required.
4. Explore the visuals, filters, and KPI cards.
5. Update the weather API connection or dataset as needed for your environment.

## Dashboard Highlights

The dashboard is designed to present weather information in a concise and visually clear format, including:

- Temperature trends over time
- Seasonal weather shifts
- Rainfall and humidity variations
- Regional and city-level comparisons
- Summary metrics for quick monitoring

## Notes

This project is intended as a weather analytics dashboard sample and may require minor adjustments depending on the API structure, data refresh settings, or the environment in which it is opened. If the API response format changes, some fields may need to be mapped or transformed accordingly.
