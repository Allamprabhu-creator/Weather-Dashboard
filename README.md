# Weather Dashboard

A Power BI dashboard project for visualizing weather conditions, trends, and key climate metrics in a clear and interactive format.

![Weather Dashboard](Dashboard.PNG.png)

## Overview

This repository contains a ready-to-open Power BI report file, `Weather_Dashboard.pbix`, along with a dashboard preview image. The project is designed to help users explore weather-related insights through interactive visuals such as:

- Temperature trends
- Precipitation and humidity patterns
- Seasonal and regional comparisons
- Weather metrics at a glance
- Visual storytelling using charts and KPIs

## Repository Contents

- `Weather_Dashboard.pbix` — Power BI report file
- `Dashboard.PNG.png` — dashboard preview image
- `README.md` — project documentation

## Requirements

To open and work with the dashboard:

- Microsoft Power BI Desktop
- A compatible Windows environment (Power BI Desktop is typically used on Windows)

## How to Use

1. Download or clone this repository.
2. Open `Weather_Dashboard.pbix` in Power BI Desktop.
3. Explore the visuals, filters, and insights.
4. If needed, refresh the data source or adjust to your own weather dataset.

## Notes

This repository is intended as a dashboard sample/project and may require data source updates depending on the environment where it is opened. If you are using your own weather data, you may need to update the data model and report connections accordingly.
